# AI Questions Log

A transparency record of what I asked AI while building this project. Paste each
prompt here, roughly in order. Keep it honest — including the throwaway questions.

Marking convention (matches `Documentation.md`): `[LC]` = me (Luis Chavez),
`[AI]` = assistant. Unmarked lines are mine by default.

## Split with `Documentation.md`

This file records **what I asked and what I did with it**. `Documentation.md`
records **why, what broke, and what I learned**. Nothing is written in both —
the journal cites question IDs instead of restating verdicts.

## Question IDs

`Q-MMDD-n` — date plus a counter within that date, e.g. `Q-0729-2`. IDs are how
`Documentation.md` refers back here. Numbering starts fresh each day.

## Verdict vocabulary

One word per question, so the file stays countable at the end of the project:

| verdict | meaning |
|---|---|
| `used` | took the answer essentially as given |
| `adapted` | took the idea, changed the implementation |
| `rejected` | did not use it — say why in one line |
| `deferred` | valid, but parked for a later phase |

**What I did with the answer (used / adapted / rejected):**
Anthropic's newest model Opus 5 agreed and offered me some suggestions on how to change the dataclasses to reflect this.
